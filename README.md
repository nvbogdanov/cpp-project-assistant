## О проекте
**C++ Project Assistant** - расширение для Visual Studio Code, предназначенное для автоматизации повседневных задач при разработке на C++.

Расширение предоставляет набор инструментов, позволяющих создавать структуру проектов, генерировать классы и исходные файлы, собирать проекты с помощью *CMake* и получать статистику по исходному коду.

Основная цель проекта - упростить организацию C++-проектов и сократить время, затрачиваемое на выполнение рутинных операций.

## Возможности
### 1. Создание C++-проекта

Команда `Create C++ Project` позволяет автоматически создать новый проект с готовой структурой каталогов:

```text
MyProject/
├── CMakeLists.txt
├── .gitignore
├── src/
│   └── main.cpp
├── include/
└── tests/
```

Особенности:
- Автоматическое создание необходимых директорий.
- Генерация файла main.cpp с примером программы.
- Создание конфигурации *CMakeLists.txt*.
- Создание файла *.gitignore*.
- Возможность сразу открыть созданный проект в новом окне VS Code.

### 2. Генерация C++-классов
Команда `Create C++ Class` позволяет автоматически создать класс с разделением объявления и реализации на два файла.

Пользователь указывает:
- Имя класса.
- Поля класса.
- Методы класса.

Например, при вводе:
```text
Имя класса: Student

Поля: int age; std::string name

Методы: void print(); int getAge() const
```

Будут созданы файлы:
```text
include/
└── Student.h

src/
└── Student.cpp
```

Также реализованы проверки:
- Корректности имени класса.
- Формата объявлений полей и методов.
- Отсутствия повторяющихся имён полей.
- Отсутствия дублирующихся сигнатур методов.

### 3. Создание C++-файлов
Команда `Create C++ File` позволяет быстро создать новый файл `.cpp` в директории `src/`.

Файл автоматически получает базовый шаблон с подключением библиотеки *\<iostream>*.

### 4. Сборка проекта
Команда `Build C++ Project` выполняет конфигурацию и сборку проекта с помощью *CMake*.

Последовательность действий:
1. Проверка наличия открытого проекта.
2. Проверка наличия *CMakeLists.txt*.
3. Конфигурация проекта.
4. Сборка исполняемого файла.
5. Вывод результатов сборки и ошибок в панели *Output*.

Используемые команды *CMake*:
```text
cmake -S . -B build
cmake --build build
```

### 5. Очистка сборки
Команда `Clean Build` удаляет директорию `build/` вместе со всем её содержимым.

Перед удалением расширение запрашивает подтверждение пользователя.

Это позволяет легко подготовить проект к новой чистой сборке.

### 6. Статистика проекта
Команда `Project Statistics` анализирует исходные файлы проекта и формирует отчёт со следующими показателями:

- Количество файлов *.cpp*.
- Количество заголовочных файлов *.h*.
- Количество непустых строк кода.
- Количество объявлений *class*.
- Количество объявлений *struct*.
- Количество вхождений *TODO*.

Результаты анализа отображаются в панели Output.

Пример отчёта:

```text
Project Statistics: MyProject
------------------------------
C++ files: 3
Header files: 1
Non-empty lines: 26
Classes: 1
Structs: 0
TODO comments: 0
```

## Установка и запуск
### Системные требования

Для работы расширения необходимы:

- Visual Studio Code версии 1.141.0 или новее.
- Node.js и npm — для разработки расширения.
- CMake версии 3.16 или новее.
- Компилятор C++, поддерживающий стандарт C++17.

Для использования функций сборки: *CMake* и компилятор должны быть установлены и доступны через системный PATH.

### Запуск в режиме разработки

1. Клонировать репозиторий проекта.

2. Открыть директорию проекта в Visual Studio Code.

3. Установить зависимости:

```text
npm install
```

4. Скомпилировать расширение:
```text
npm run compile
```

5. Открыть панель Run and Debug.

6. Выбрать конфигурацию Run Extension.

7. Запустить расширение.

После этого откроется новое окно Visual Studio Code с работающим расширением.

### Создание установочного файла VSIX

Для создания установочного пакета необходимо установить зависимости проекта и выполнить команду:

```text
npx vsce package
```

Перед упаковкой автоматически выполняется компиляция расширения.

В результате в корневой директории проекта будет создан файл:

`cpp-project-assistant-0.0.1.vsix`

Полученный файл можно передать другим пользователям для установки расширения в Visual Studio Code.

## Список команд
Все команды доступны через палитру команд Visual Studio Code - `Ctrl + Shift + P` (Cmd + Shift + P на macOS).

|Команда|Назначение|
|---|---|
|Create C++ Project|Создание нового C++-проекта|
|Create C++ Class|Генерация C++-класса|
|Create C++ File|Создание исходного .cpp-файла|
|Build C++ Project|Конфигурация и сборка проекта|
|Clean Build|Удаление директории сборки|
|Project Statistics|Получение статистики проекта|

## Известные ограничения
- Подсчёт классов, структур и других элементов статистики основан на регулярных выражениях, а не на полноценном анализе синтаксиса C++.

- Проверка объявлений полей и методов поддерживает распространённые варианты синтаксиса, но не все конструкции языка C++.

- Сгенерированные реализации методов содержат базовые шаблоны, которые при необходимости нужно дополнить самостоятельно.
